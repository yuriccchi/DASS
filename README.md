# DASS
Лабораторные работы по курсу Проектирование архитектуры программных система в НИУ ВШЭ - Пермь.

В лабораторных работах рассматривается выбранная тема ВКР **"Автоматизация работы учебных ассистентов"**.
Преподаватели ВУЗа, имеющие под руководством учебных ассистентов, заинтересованы в повышении скорости и качестве проверок студенческих работ. Для этого было решено провести автоматизацию данного процесса и разработать веб-приложение.

+ **Пользователи**: около 5 преподавателей, до 100 студентов-ассистентов в одновременных пользователях.
